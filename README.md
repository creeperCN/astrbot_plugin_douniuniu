## ✨ 本分支改动（v0.0.8，适配 AstrBot v4.27.3）

- **适配 AstrBot v4.27.3**：改为相对导入与公开 API 路径，资源文件按插件目录定位，任意目录名均可加载。
- **新增命令**
  - `/停止锻炼`、`/停止打工`：立即停止，按已完成时长结算、收回未完成奖励（修复“开工即全额发放”可被刷取的问题）。
  - `/牛牛管理`（牛牛管理员/超级用户，需 @目标）：`金币`、`长度`、`硬度`、`深度`、`敏感度` 五项数值修改；金币支持 `+100`（加）、`-100`（扣）、`100`（设为）。
- **数值平衡（长期向）**
  - 壮丁手术卡：成功由「长度翻倍」改为「长度 +20%，单次上限 100cm」；失败由「减半」改为「-10%」。
  - 决斗「劣势获胜」的奖励与惩罚由 ±10~20 调整为 ±5~10。
- **安全加固**
  - 决斗冷却（默认 120 秒，配置项 `battle_cooldown`）；平局不再双方增长。
  - 注销牛牛收取 200 金币手续费（防无限重roll刷初始属性）。
  - 被锁方短时免疫（防多人围锁）。
  - 修复杀虫剂数量多扣/负数自锁、空名字、排行负数、超管 ID 数字字符串不兼容等问题。
  - 寄生虫主人注销后不再导致崩溃。
- **全新帮助图与商城图**：`/牛牛帮助`、`/牛牛商城` 文案与当前机制保持一致。

## 🚀 安装

1. 面板安装：上传 `astrbot_plugin_douniuniu-remake-v4.27.3.zip`（已安装旧版请先在面板卸载，卸载时**不要勾选删除配置**）。
2. 或手动安装：将本仓库克隆到 AstrBot 的 `data/plugins/douniuniu/` 目录，重启 AstrBot。
3. 无需额外依赖（`requirements.txt` 中的 apscheduler 为 AstrBot 自带依赖）。

## 🎮 使用命令

以下命令需要以 `#` 或 `/` 开头，或者直接 @机器人 发送命令。

### 普通用户命令

| 命令 | 说明 |
|---|---|
| 牛牛帮助 | 查看牛牛所有指令 |
| 创建牛牛 | 创建你的牛牛，随机获得长度和硬度属性 |
| 注销牛牛 自己/@某人 | 注销并清空数据（手续费 200 金币），注销别人需管理员 |
| 牛牛排行 n | 查看当前群内排名前 n 位的庞然巨物 |
| 牛牛进群 | 将你的牛牛加入本群，加入后才能使用其他功能 |
| 牛牛签到 | 每日签到 |
| 牛牛决斗 @XXX | 与 XXX 的牛牛进行决斗（有冷却） |
| 牛牛取名 XXX | 为你的牛牛取名，限制 5 个中文字符内 |
| 我的信息 / 查看信息 @XXX | 查看自己/他人的信息 |
| 牛牛商城 | 展示商城所有商品以及金币数 |
| 购买 编号 n / 使用 编号/道具名 | 购买/使用道具 |
| 牛牛背包 | 展示背包内的道具以及数量 |
| 打胶 | 为自己导一发，有冷却时间 |
| 锁牛牛/吸猫猫 @XXX | 与其他用户进行互动 |
| 锻炼 n / 停止锻炼 | 锻炼 n 小时；停止时按已完成时长结算、收回未完成奖励 |
| 打工 n / 停止打工 | 打工 n 小时；停止时按已完成时长结算、收回未完成工资 |
| 转账 金额 @XXX | 向指定用户转账金币 |

### 管理员命令（牛牛管理员）

| 命令 | 说明 |
|---|---|
| 开启牛牛 / 关闭牛牛 | 开启/关闭本群牛牛功能 |
| 强制注册 @XXX | 为对方强制注册牛牛 |
| 牛牛管理 | 管理员特权，修改指定账号数值（金币/长度/硬度/深度/敏感度，需 @目标） |

### 超级用户命令（bot 持有者）

| 命令 | 说明 |
|---|---|
| 添加/删除牛牛管理员 群号 QQ | 管理群牛牛管理员 |
| 超能力 n | 向自己账户添加 n 个金币 |
| 配置 添加/删除名字非法词 词 | 取名禁用词管理 |
| 配置 打胶cd 秒 | 设置打胶/自摸冷却时间 |

## ⚙️ 配置项（面板「插件配置」）

`superusers`（超级用户 QQ）、`disabled_name`（取名禁用词）、`do_self_cooldown`、`do_other_cooldown`、`battle_cooldown`（决斗冷却）、`max_work_hours`、`max_exercise_hours`、`coins_per_hour`、`trans_time`。
